# MSTRMND Layer

Interactive WebGPU visualization of the MSTRMND operating layer — the space between human ambition and machine execution.

Built with [vgpu](https://vgpu.sh) to match the live brand at [mstrmnd.ai](https://mstrmnd.ai): Space Grotesk, near-black field, lime signal `#d8ff3e`, orbital core.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173. Chrome 113+ or Edge with WebGPU enabled.

```bash
npm run check      # validate the WGSL
npm run snapshot   # headless PNG via vgpu/node (software renderer)
npm run build
```

## What it is

Pointer input is **ambition**. The field at the edges is **trapped intelligence** — fragmented, cellular, uncoordinated. The center is the **layer**: a governed core with orbital routing. Three satellites stand for the selected systems:

1. Orchestration — Pipeline Context
2. Context — Editorial Circuit
3. Governance — Release Gate

Move through the canvas and the signal coheres toward execution.
